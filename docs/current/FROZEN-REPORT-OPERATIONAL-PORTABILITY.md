# Frozen report operational portability repair

5 October 2026, isolated base `987f82de`. The existing data-exit contract failed because the export declared migration `0026_work_burden_sessions` while the installed schema had reached `0028_indicator_figure_disclosures`. The five frozen-report tables were also missing from the portability table contract. This repair handles the tables and privacy relationships together rather than changing only the version string.

## Export boundary

The organisation archive identifies migration 0028 and represents all five new tables. Current active owners retain the existing organisation export authority. Exported frozen figure metadata additionally requires the current reporting role and purpose and normal access to **every original cohort member**, without emergency or owner bypass. If any member or an included parent is inaccessible, the entire figure, dependent event history and receipts are withheld. Current authority is checked again after export audit before the response. Withholding counts and notes distinguish protected or out-of-scope material; admin owners receive no patient-linked report metadata, event history or outcomes.

`indicator_figures` exports its exact immutable scalar header, including original digest and parent relationship, with `data` omitted. That field contains report cells, series and unit hashes whose direct release would bypass the current viewer/edition disclosure checks. `indicator_figure_events` retains exact immutable original author/reviewer lifecycle history for included figures. `indicator_figure_receipts` retains only stored fixed-shape outcomes (`figureId`, `eventId`, `sequence`, `status`) matching an included event, original actor and sequence. Unsupported saved result bodies are withheld whole. Historical author/reviewer roles and receipt outcomes are provenance, not imported current authorization or a new clinical/publication approval.

`indicator_figure_units` and `indicator_figure_disclosures` have explicit empty export files and withheld row counts. The manifest also names their protected purpose in exclusions. Per-person unsuppressed counting material and the retained disclosure privacy ledger remain server-only. No original figure, counting unit, receipt, event or privacy ledger is rewritten or deleted. Source digests are preserved as provenance; the operational archive cannot recompute a protected figure digest without omitted original material.

**Ordinary operational export is not a full report reconstruction archive.** Metadata/history portability does not complete B27/B31 governed reproducibility or full protected report portability. A separately governed privileged restore/reconstruction contract, its issuer/receiver authorization, protection-state treatment and acceptance remain buildable residual scope. Clinical and official reporting acceptance also remain pending. This repair does not close those clauses by omitting data.

The verifier checks figure parent references, event and receipt figure links, complete lifecycle sequence, original author preparation/publication and independent approval lineage. It refuses unexpected figure columns, raw counting units or disclosure rows, unsupported receipt outcomes, dangling relationships and self-review history even when a forger recomputes archive checksums and manifest totals. Export metadata is not a substitute for current server reporting authorization.
