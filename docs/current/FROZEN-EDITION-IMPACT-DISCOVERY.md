The existing released-figures workspace now discovers current impact automatically on its scoped50-row metadata page, on an individual metadata read and beside a protected immutable edition view. A refresh control makes the current check explicit. Fixed states distinguish:

- **counting-affected**: a pinned counting primitive, numerator/denominator dependency, cohort/filter/exclusion membership or grouping changed;
- **source-revised**: relevant retained source evidence changed, with unchanged pinned counting contributions;
- **coverage-unknown**: retained counting coverage is older thanV3, or exact pinned definition authority cannot safely be compared;
- **unchanged**: supported current coverage and pinned inputs/source evidence compare equal.

No patient identifiers, primitive values, cells, change counts or count deltas appear in impact metadata. The audit records only an immutable edition/current-basis SHA-256; it contains no patient data or change counts. Discovery is evidence for review, never clinical correction, automatic replacement, publication, outbound sending or retry. Source-only changes must be reviewed for relevance; they are not labeled changed report counts.
