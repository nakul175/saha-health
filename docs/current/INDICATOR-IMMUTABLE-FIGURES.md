# Immutable population-based figures and reviewed reissues

This author slice implements buildable B27 population snapshots/reissue software alongside the separately committed definition lifecycle and reporting-clock repair. It does not confer clinical denominator approval or official publication authority. All UI publications explicitly remain synthetic software demonstrations pending external acceptance.

## Boundary and custody

`/indicator-figures` is an authenticated owner/supervisor reporting journey linked from definition review. Owners prepare figures from the existing released/effective registry and fixed indicator vocabulary, independent current reporting managers approve/reject, and the original reporting owner publishes. A reissue has a new identifier, original-parent link, independent review and new publication. Original payloads, definitions, population evidence, digests, events, command receipts and disclosure evidence are append-only. Earlier figures are never recalculated or rewritten. Saved identifiers and paged authorised history allow older records to be reopened.

The separate historical reporting cutoff is retained across a reissue. The new edition captures the current source records for that historical window. Frozen full definition records preserve numerator/denominator, filters, exclusions, method, cadence and owner alongside original governance references. Source revisions, fixed counting material and an integrity digest preserve reproducibility; no synthetic retrospective source records are constructed when original evidence is missing.

New protected D1 migration 0027 creates figure headers, per-person counting units, lifecycle events and exact actor/key/body-hash receipts. Migration 0028 adds durable original-viewer disclosure evidence. The latter is separate because 0027 had already been applied in synthetic author checks; its migration bytes were retained unchanged. Every table has immutable update/delete guards. All lifecycle inserts and their receipt/audit append share an organisation/patient-revision CAS transaction. Losing guards write no partial figure. Applied prior migrations and confirmed server care/audit history remain untouched.

Counting evidence is protected patient-derived data, not anonymous data. It retains original patient IDs/versions, visit revisions, hashed cohort/group dimensions, event timestamps, minimal fixed numeric counting inputs and a one-way repeat signature. It contains no names/contact, clinical measurements, answers, notes, original visit bodies or media. The hash is an integrity tool, not a claim of anonymisation. Existing D1 custody applies; no extra deployment storage is fabricated.

## Authority, release and privacy

Trusted identity precedes local body/query parsing. Current active reporting role, purpose and access to every original population patient are required before prepare/review/publish/reissue/view, metadata/history and receipt replay. Historical evidence cannot grant current access. Review/publication also require unchanged full prepared population, source hashes and pinned definition authority. Publication checks the independent reviewer's current role/version/purpose and original cohort access. Stored publications can survive source corrections, while current access withdrawal still denies their display. Missing/incomplete evidence fails closed. A second fresh check after disclosure audit prevents a withdrawal during that commit from returning cells.

Human figure cells use the existing original-viewer small-cell, complementary, population/overlapping-window and seven-day differencing protections. They never reuse destination-screened aggregate payload cells. Refusals retain the existing rate budget. A new additional durable edition guard compares actual per-person fixed-measure contributions against prior editions that this same viewer actually received. A small changed set is withheld even when both edition totals individually exceed five. Previously authorised disclosures are not silently expired or overwritten. Concurrent first disclosures use a guarded append so both conflicting editions cannot escape before one is registered.

The edition comparison is conservative and can withhold legitimate small changes. When an earlier disclosed original cohort cannot currently be read, a new edition comparison fails closed. It supplements the existing fixed-measure privacy model; unrelated-measure correlation, collusion and ordinary live-query data changes retain that model's stated residual limits. It is not a proof of universal statistical anonymity. The retained edition guard has an explicit 2,000-disclosure processing bound; exceeding it refuses further cells and requires an approved archival/capacity policy, without dropping old evidence. Real deployment resource/capacity acceptance remains external.

## UI and outcome proof

The phone UI supports preparation, independent review, publication, protected opening and reissue; it displays immutable identifiers/digests/history and clinical-pending notices. Pending mutations preserve their original actor/body/key in the current tab, block different actions and offer explicit unchanged-key reconciliation after an unknown acknowledgement. It does not promise durable pending-action recovery after closing/reloading the tab. These metadata-only figure commands do not send external messages or providers. Account changes/current permission failures clear displayed cells and metadata. Browser checks use ordinary 390px touch targets, not forced/focus clicks.

Storage bounds are explicit: 6,000-byte request, eight fixed-vocabulary definitions, existing 1–366-day window, 512 KiB header, 128 KiB counting unit and 8 MiB complete material. Failure saves no partial capture and preserves existing figures. These are storage guards, not new clinical ranges. Pagination returns only currently accessible figure references; no hidden original-population IDs or cells appear in metadata.
