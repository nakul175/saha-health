Prove actual Worker/D1 audit-write failure returns no delta, command outcome remains retryable with the same receipt, and audit-only writes move no patient revisions. Preserve read-before-return ordering and bounded counts; do not manufacture another full-caseload audit.
2. **Prepared offline record opens (larger, coordinate A05).** The existing online `record-opened` endpoint reports a scoped screen open and coalesces within a minute. The encrypted field/app renderer has no corresponding offline open ledger. Add a bounded encrypted local open-event queue tied to the signed packet/account/organisation/grant and explicit client occurrence identity/time; flush on reconnect with current identity and scope, idempotent append and privacy-safe counts. Distinguish client-reported historical offline access from server-observed online reads. Do not claim the server can durably approve an offline open before network access exists, and do not weaken current grant locks to deliver telemetry.

Add a central immutable command authority envelope using the authenticated current membership and specifically relied-on delegation, plus initiating human / executing service only where applicable. Avoid clinical content and duplicating all grants as relied-on authority. Cover patient commands, org commands, revocation, command replay and delegation expiry without rewriting old audit-chain history.
