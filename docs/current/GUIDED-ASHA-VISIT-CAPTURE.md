## Response uncertainty and deliberate review

The original ordinary command interface returns `null` for both a known refusal and an unconfirmed transport response. Guided capture reports **Save response not confirmed**, retains entered facts/answers and blocks another capture save or confirmation until explicit current-record comparison. It never infers that the operation failed. View current saved record reads the existing scoped workspace and opens the original comparison; View receipts and trace opens the original delivery/trace view. Neither action resends a command. The deliberate Load saved record now explicitly replaces local facts even when the saved revision has not changed; same-revision manual merge explicitly retains the chosen local edits. Original CAS, role, patient checks, closed-record restrictions and dirty navigation guard remain.

Exact local command receipt lookup is a remaining focused software task. This batch provides current saved-record review and the original external receipt actions, not a newly invented receipt authority or durable tab-close recovery.

This online capture requires a connection. Offline entry remains the existing signed prepared packet and encrypted device vault at `/app/offline/`; this guide does not create plaintext chat/history or claim online capture works offline. Language follows the existing membership preference: English and draft Hindi navigation with original translated measurement controls and explicitly English programme/governance content.
