# Legacy alert fixtures for the combined-reviewed adapters

6 October 2026 (IST). The four combined-reviewed alert adapters (`combined-reviewed-alert-recipient-hold-http`, `-recipient-current-http`, `-recipient-current-scheduled`, `-export-cold-independent-http`) check that history written by the OLD runtime is retained by the current Worker. They therefore need state generated by the original older source, not by this build.

## Why the adapters failed

- The hold and scheduled adapters read `tests/evidence/alert-transition-guidance-root-integration/alert-recipient-*/observed.json` (never created) and a legacy state under `../saha-alert-disclosure-author/` (not present). The original before-evidence `tests/evidence/alert-disclosure-before/observed.json` cannot be reused with a regenerated state, because organisation and owner ids are random per run; evidence and state must come from one run.
- The scheduled adapter read the current-http proof from its own folder and a fresh-small state under a name the current-http adapter never wrote. The runner also restores tracked proof files after every suite, so the proof is now stored next to its state under `.wrangler/`.
- The export-independent adapter copied a cold state and `legacy.json` that no step produced.
- Legacy databases lack migrations 0031 and 0032. The builder applies, forward only, the migrations present here but not in the old source; no data is rewritten.

## Build

```
SAHA_CHROMIUM=<chromium> node scripts/build-legacy-alert-fixtures.mjs
```

Local objects and the local pnpm store only. It creates detached worktrees `../work/legacy-75c0` and `../work/legacy-8eed` (override with `SAHA_LEGACY_WORK`), installs with `--frozen-lockfile`, builds each, and then:

1. Runs the original `tests/alert-disclosure-before.mjs` byte for byte on `75c0f3e5372b9eb08eab0717966b4638163294bc` (29 assertions, ports 20720-20722).
2. Runs the original `tests/alert-export-cold-http.mjs` with `SAHA_ALERT_EXPORT_PHASE=legacy` on `8eedc606ef015bd2cf5a8bddb3ed9e50249b5a30` (17 assertions, port 21221), upgrades a copy with the missing migrations, then runs the same driver with phase `current` on this build (port 21221) as the documented sequence requires.

Outputs (git-ignored, owned names; originals are never touched):

| Name | Used by |
| --- | --- |
| `.wrangler/alert-disclosure-before-state-combined-review`, `.wrangler/alert-disclosure-before-evidence-combined-review/observed.json` | hold, scheduled |
| `.wrangler/alert-export-cold-state-combined-review`, `.wrangler/alert-export-cold-evidence-combined-review/legacy.json` | export-independent |
| `.wrangler/alert-disclosure-current-state-combined-review`, `.wrangler/alert-disclosure-current-evidence-combined-review/observed.json` | written by `combined-reviewed-alert-recipient-current-http`, read by the scheduled adapter |

The tracked `tests/evidence/alert-transition-guidance-root-integration/legacy-fixtures/manifest.json` records source SHAs, driver digests, assertion counts, forward migrations and state/evidence digests of the last build. Digests differ on every rebuild because ids are random.

## Order and overrides

Run the suites with `node scripts/test.mjs integration --only <id> --fast --guard`: hold, current-http, then scheduled (it needs the state and proof current-http just wrote), then export-independent. Paths can be overridden with `SAHA_ALERT_BEFORE_EVIDENCE`, `SAHA_ALERT_LEGACY_STATE`, `SAHA_ALERT_CURRENT_STATE`, `SAHA_ALERT_HTTP_PROOF`, `SAHA_ALERT_EXPORT_STATE`, `SAHA_ALERT_EXPORT_LEGACY`. A missing fixture stops the adapter with the build command; nothing is skipped or invented.
