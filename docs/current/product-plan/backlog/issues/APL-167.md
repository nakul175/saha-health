## User / outcome

As a worker using assistive technology or enlarged text, I want essential tasks to have labelled controls, readable scaling, navigable focus and non-colour status cues, so I can complete the same permitted journeys accessibly.

**Scope boundary:** Preserve WCAG 2.2 AA for web and corresponding applicable mobile/native principles. Automated checks do not substitute for manual assistive-technology and representative-user review.

## Original requirement and acceptance text

### NFR-13 — Accessibility

Priority: Must; original release: R1.

Web workflows shall target WCAG 2.2 AA; mobile workflows shall implement corresponding applicable principles and native accessibility support \[S6\]. Essential tasks shall support readable scaling, labelled controls, focus navigation and non-colour status cues.

Verification: Automated assessment plus manual assistive-technology and representative-user testing covers all core journeys.

## Additional CWO acceptance / refusal criteria

* **CWO-002-AC04 (New acceptance)**: Given the specified compact phone viewport, the primary next action is visible without horizontal scrolling and remains operable with touch and keyboard.
* **CWO-009-AC01 (New acceptance)**: The evidence names the exact handset, OS, browser/app, build, synthetic caseload and network mode; results are reproducible from that profile.
* **CWO-009-AC02 (New acceptance)**: Every essential control remains visible or reachable with the keyboard open and at 200% text size, with no horizontal page overflow at the reference viewport.
* **CWO-009-AC03 (New acceptance)**: Essential controls have accessible names and a usable focus order; screen-reader testing reaches, activates and corrects the core visit fields.
* **CWO-009-NEG03 (Expected refusal / recovery)**: Keyboard occlusion, unreachable actions or storage failure without an accurate receipt cause a failed relevant criterion.
* **CWO-009-RJ01 (Delivery rejection)**: Reject a blanket accessibility or offline certification derived from a single screenshot or automated scan.
