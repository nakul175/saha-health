## User / outcome

As a frontline worker queueing permitted media, I need to see the purpose, quality, permission, retention and pending state of each recording or image, so that reconnection cannot upload media whose authority expired or capability was suspended.

Bounded scope: Recheck eligibility and authorisation before provider dispatch; cancelled or held work remains distinguishable from a successful invocation, and withdrawal does not block otherwise permitted care.
