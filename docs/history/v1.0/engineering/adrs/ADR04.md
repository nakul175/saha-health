# ADR04 Native field client

Status: Proposed

## Decision

Use an Android reference client with encrypted local storage and keystore wrapping.

## Rationale

Offline lease and media recovery require controlled device behaviour.

## Consequences

Web admin supports online work; browser storage is not the default clinical offline store.

Authority: BRD v1.1; High Level Design v1.0. Review owner: architecture lead with relevant clinical, privacy or integration owner. Acceptance remains open.
