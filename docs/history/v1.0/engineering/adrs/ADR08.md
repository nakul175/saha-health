# ADR08 Versioned capability activation

Status: Proposed

## Decision

Activate provider and model version per deployment and scope.

## Rationale

Evidence and local permission differ from a successful API test.

## Consequences

Substitution requires equivalent approved intended use.

Authority: BRD v1.1; High Level Design v1.0. Review owner: architecture lead with relevant clinical, privacy or integration owner. Acceptance remains open.
