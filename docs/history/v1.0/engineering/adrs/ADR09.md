# ADR09 Explicit exchange scope

Status: Proposed

## Decision

Implement ABDM and direct EHR as separate connector types.

## Rationale

Consent or API availability does not grant universal records access.

## Consequences

Exact external contracts stay blocked until owner verification.

Authority: BRD v1.1; High Level Design v1.0. Review owner: architecture lead with relevant clinical, privacy or integration owner. Acceptance remains open.
