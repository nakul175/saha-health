# ADR12 Explicit synthetic environment

Status: Proposed

## Decision

Simulators emit mode and source markers and use isolated fixtures.

## Rationale

Development can exercise failures before partner credentials exist.

## Consequences

Simulation evidence cannot pass live connector or clinical validation gates.

Authority: BRD v1.1; High Level Design v1.0. Review owner: architecture lead with relevant clinical, privacy or integration owner. Acceptance remains open.
