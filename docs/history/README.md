The extracted `v1.0/` tree includes all ten Word specifications, the workbook, prototype, manifest, source BRD, contracts, fixture recipes, test catalogue, twelve ADRs and saved design-check results. Both ZIP archives are also preserved exactly. No historical script was run in place to overwrite its original evidence.

These review aids do not replace original formatting, diagrams, formulas or validation rules.

Only versions recovered from the original pack are claimed. BRD v1.1 was already the source for documentation v1.0; this does not imply a recovered BRD v1.0 exists. Historical relative links inside the old README remain in their original bytes and may refer to its former repository-root location.
