# API contract

Owner: Nakul Jain · Last reviewed: 2026-10-08 · Update trigger: any change to `app/api/**`, the command schemas or `scripts/build-documentation.py` output.

**There is no OpenAPI document for the running application.** The only OpenAPI file in the repository, `docs/history/v1.0/engineering/openapi.json`, describes the original proposed design (74 REST operations, 16 event types) and is preserved unchanged. The running system differs: it exposes **96 HTTP method/route pairs** under `app/api/` and a single authenticated JSON command endpoint carrying **253 command schema discriminators** ([Current API inventory](../current/CURRENT-API-INVENTORY.md)).

## Conventions that matter to callers

- Identity comes only from the trusted provider in `lib/saha/identity.ts`; never from request bodies ([access-control model](ACCESS-CONTROL-MODEL.md)).
- Commands carry an idempotency key and CSRF controls and are version-bound; a replay rechecks current access ([Operations, API and schema](../../OPERATIONS.md)).
- Streamed command bodies stop at 20,000 bytes.
